# AimStation

Download AimStation for Windows 10 / 11 (64-bit) from the [Releases](https://github.com/aim-station/AimStation/releases) page.

Each release has the installer (`AimStation-<version>-Setup.exe`) and a zip of it (`AimStation-<version>.zip`), with short update notes.

Website: https://aimstation.gg
